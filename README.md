# Task 1: Data Cleaning & Preprocessing
Elevate Labs - AI & ML Internship

## Objective
Learn how to clean and prepare raw data for ML.

## Tools Used
Python, Pandas, NumPy, Matplotlib, Scikit-learn

## Steps Done (As per PDF)
1. Imported dataset and explored nulls, data types
2. Handled missing values using mean/median/mode imputation
3. Converted categorical to numerical using Label & One-Hot Encoding
4. Normalized/Standardized numerical features
5. Visualized outliers using boxplots and removed them with IQR method

## Dataset
Titanic Dataset from Kaggle
https://www.kaggle.com/datasets/yasserh/titanic-dataset

## Output
- cleaned_titanic.csv - final cleaned data
- boxplot_before.png / boxplot_after.png - outlier visualization

## What I Learned
Data cleaning, handling nulls, encoding, feature scaling, outlier detection.
